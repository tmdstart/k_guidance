food_crawl.ipynb	방문할만한 서울시 음식점 데이터를 수집하고 분석하는 Jupyter Notebook.
seoul_resturant.ipynb	서울시 음식점 데이터를 수집하고 처리하는 Jupyter Notebook.
interpark_concert_ticket.py	인터파크 콘서트 티켓 상세 정보를 수집하는 스크립트.
interpark_concert_sql.py	수집된 콘서트 데이터를 SQL 데이터베이스에 저장하는 스크립트.
interpark_concert_sql_location.py	콘서트 공연장 위치 데이터를 수집 및 처리하는 스크립트.
interpark_musical_ticket.py	인터파크 뮤지컬 티켓 상세 정보를 수집하는 스크립트.
interpark_musical_sql.py	수집된 뮤지컬 데이터를 SQL 데이터베이스에 저장하는 스크립트.
interpark_musical_sql_location.py	뮤지컬 공연장 위치 데이터를 수집 및 처리하는 스크립트.
대한민국구석구석_festival.py	대한민국 구석구석 웹사이트에서 축제 정보를 수집하는 스크립트.
transform_csv.py	데이터베이스 또는 기타 소스에서 데이터를 추출하여 CSV 파일로 변환하는 스크립트.
